# 爆款拆解

## 何时用

- 用户丢来一条抖音/小红书链接，或把口播文案贴过来
- 用户问「这条为什么火」「我能学什么」

## 输入从哪来

按可靠性排序，缺就往下退，并如实告诉用户用了哪一种：

1. 视频本身（有链接且能看）
2. 用户贴的文案/字幕
3. 用户口述的内容（明确标注「据用户描述」）

**只有播放量没有内容**时，只记数据，不做结构拆解。

## 拆什么

| 维度 | 要回答的问题 |
| --- | --- |
| 钩子 Hook | 前 3 秒说了什么、用了哪种手法（反常识 / 痛点 / 身份代入 / 结果前置 / 悬念） |
| 证明 | 凭什么让人信（亲历 / 数据 / 对比 / 权威） |
| 结构 | 分段时间轴，每段一句「这段在干什么」 |
| 节奏 | 多久一个信息点、有没有空镜、转场方式 |
| CTA | 有没有、在第几秒、引导评论还是主页 |
| 可迁移结论 | 一句能写进卡片的结构，**必须用 A → B → C 形式** |

## 写回 benchmarks.json

追加到 `items[]` 顶部（最新的在前），`id` 用 `benchmark-` + 四位序号（取现有最大值 +1）。

```json
{
  "id": "benchmark-0043",
  "title": "视频标题或首句",
  "creator": "作者名",
  "platform": "抖音",
  "plays": "128.4w",
  "likes": "1.2w",
  "capturedAt": "2026-10-26",
  "method": "反常识",
  "status": "待沉淀",
  "statusTone": "",
  "hook": { "type": "反常识", "text": "前 3 秒的话术要点（改写，不照抄）", "metric": "0–3s · 3 秒留存 68%" },
  "proof": { "type": "亲历 + 对比", "text": "用了什么证据", "metric": "18s / 27s 两处证据" },
  "timeline": [
    { "t": "0:00–0:03", "d": "这段在干什么" }
  ],
  "rhythm": "平均 7s 一个信息点，无空镜",
  "cta": "0:45 反问，引导评论",
  "takeaway": "否定共识 → 案例 → 一句话模板 → 反问"
}
```

## 禁止

- **不抄原文、不抄画面**。引用不超过一句，且要标注是引用。
- 不许凭标题猜内容结构；没看到内容就说看不到。
- 不许给「因为它火了所以会火」这类循环解释。
- `takeaway` 必须能脱离原视频成立——换个题材也能用。
- 播放/点赞数字只写看到的，不确定就写「约」。

## 完成后

告诉用户：这条最值得拿走的一个结构、以及它跟你账号的契合度（高/中/低 + 原因）。
