# skills/writing/ — 写作风格包

> 来源：`D:\在场感写书\03_写作笔记\核心命题.md`（风格判断）+ `金句候选.md`（语感样本）+ L3 对话中他对文案的 20+ 次修改意见。
> 用途：AI 替他写任何东西（书稿、文案、话术、PPT）之前，先读这份。

---

## 一、风格定调（4 条，来自核心命题.md）

1. **偏叙事**（讲故事、嵌入金句），**但保持理论精度**
2. **每章/每节有一个核心场景或案例**作为切入点
3. **不空谈哲学**——每个论点都对应一个**可观察的身体信号或教学动作**
4. **不软化原理论的锐度**，保留真实细节

## 二、句式规律

| 特征 | 说明 | 例子 |
|---|---|---|
| 短句为主 | 一句话一个意思，不绕 | 「不是学会在场，是想起你本来就在。」 |
| 破折号转折 | 前半否、后半立 | 「在场感不是让你活得更好，是让你……」 |
| 对比对仗 | A 与 B 直接对撞 | 「解题=被动应答，出题=主动探索。」 |
| 身体锚点 | 抽象概念必须落到身体 | 「肩膀紧/呼吸浅/胃缩」 |
| 具象场景开头 | 不用概念开头，用画面 | 「你小时候蹲在地上看蚂蚁搬家，看半小时」 |
| 反问收尾 | 交还给读者 | 「你做这件事，是为了被看见，还是因为想做？」 |

## 三、禁忌

- ❌ 炫技（「你是在炫技，就像749局」）
- ❌ 细节停在表面——「细节不是呼吸，而是因为呼吸而勾起的对妈妈的思念」
- ❌ 宏观空泛，不从细节入手
- ❌ 堆概念（「太复杂了」）
- ❌ 空谈哲学不落地
- ❌ 软化锐度（把真话写得四平八稳）
- ❌ 营销文案里直接推报名（要「先种草」）
- ❌ 说「课程顾问」「这次打电话不是推销」

## 四、金句样本（按主题，可直接引用）

**核心命题**
- 「在场感不是让你活得更好，是让你在AI时代，还能做一个不被数字污染的人。」
- 「不是学会在场，是想起你本来就在。」
- 「在 AI 时代，人最大的稀缺不是会做什么，而是'在不在'。在不在，不靠学会，靠想起。」

**身体与开关**
- 「身体信号不是副产品，是主产品。」
- 「肩膀紧/呼吸浅/胃缩——这是不在场的报警器，不是分心的证据。」
- 「身体先动，脑子后跟。」

**出去—回来**
- 「在场=出去且回来，不在场=只出去回不来，或只待在原地出不去。」
- 「你不是那个焦虑，你是那个知道'我在焦虑'的人。分开了，你才能真的看见哪件是你的。」

**AI 镜子**
- 「AI 是帮你回到自己的那面镜子——它不评价镜子里的人，只管照清楚。」
- 「AI 跳过了'我不确定'的那个瞬间——而那个瞬间恰恰是在场感要保护的。」

**解题与出题**
- 「解题=被动应答，出题=主动探索。被动应答是借来的生命，主动探索才是自己的。」
- 「如果人生是一张考卷，你现在想给自己出什么题？」

**教育批判**
- 「传统课不差，但它有一个副作用：它让人学会了'在不在不重要，做对了才重要'。」
- 「难的往往不是事情本身，是你跟它之间的那团乱。」

**节奏**
- 「节气不是被安排的，是天地的节奏本来就在那里。」
- 「大寒之后就是立春——毕业不是结束，是下一个惊蛰到来前的最后一口气。」

**内在标准**
- 「不是问'这题对吗'，而是问'做的时候哪一刻我忘了时间'。」

**教练**
- 「守住手，不要替他总结。」
- 「教育不是填满一个桶，是点燃一把火。火不是你点的，是他自己本来就有的。你只是把风挡住了，让火别灭。」（来源：专家圆桌 Resnick，**非他本人原话**，引用时标注）

## 五、不同载体的差异

| 载体 | 风格调整 |
|---|---|
| **书稿** | 叙事 + 金句，每章 3000-5000 字，章末「今晚试试」 |
| **短视频/小红书文案** | 先种草不推报名；强化人设「43岁 + 初三孩子爸」；三条线 6:2:2 |
| **话术** | 一页 A4 一眼找到；简表+详表结构一致；每个类型都要有示范 |
| **宣言/纲领** | 只写纲领，**不加「怎么练」的章节**（他明确反对过） |

## 六、自检清单（写完过一遍）

- [ ] 第一句是不是精简干练？
- [ ] 有没有一个具体场景/案例作为切入点？
- [ ] 每个抽象论点是否对应一个可观察的身体信号或动作？
- [ ] 有没有炫技/宏观/空谈？
- [ ] 锐度有没有被软化？
- [ ] 金句密度是否超标（每章 2-3 个）？
- [ ] 引用别人的话有没有标来源？
